How to play the download

  1. Click Download for Windows to get StarForge.exe.
  2. Double-click it. The game opens in its own window and works offline.
  3. If Windows shows "Windows protected your PC", click More info → Run anyway. This appears for any new game that isn't code-signed.
  4. If Windows says it blocked the file (Smart App Control), use Play in browser instead. It's the exact same game.

Mac/Linux: unzip StarForge.zip and open star-forge.html in any browser.
